# Kiwame brand

**Kiwame** (極め, *kee-WAH-meh*) is the Japanese word for an expert's final verdict: historically
the certificate a master appraiser wrote to prove a sword or artwork genuine. The verb *kiwameru*
means to master something, to investigate it through to the very end. That is the product: an AI
QA engineer that knows your app end to end and certifies what works.

**Tagline:** The AI QA engineer that knows your app end to end.

## The mark

A vermilion appraiser's seal. Inside it, a **K** whose lower leg is a **check mark**: Kiwame, verified.
The thin inner border is the seal's frame; drop it below 32 px (use the *simple* mark).

| File | Use |
|---|---|
| `kiwame-logo.svg` / `kiwame-logo-white.svg` | Horizontal logo (seal + wordmark) on light / dark backgrounds |
| `kiwame-mark.svg` | The seal alone, 32 px and up: avatars, docs, splash |
| `kiwame-mark-simple.svg` | Full-bleed seal without the inner frame: favicons, 16–32 px |
| `kiwame-mark-black.svg` / `kiwame-mark-white.svg` | One-colour versions for print, embossing, single-colour UIs |
| `kiwame-wordmark.svg` / `kiwame-wordmark-white.svg` | The name alone |
| `kiwame-app-icon.svg` | App icon source (macOS proportions, gradient and shadow) |
| `png/kiwame-app-icon-1024.png` | Source for `npx tauri icon` (desktop icons in `desktop/src-tauri/icons/`) |
| `png/kiwame-mark-{32…512}.png`, `png/kiwame-favicon-{16,32}.png`, `png/apple-touch-icon.png` | Raster sizes |
| `png/kiwame-logo.png` / `png/kiwame-logo-white.png` | Logo for places that need a PNG (slides, email) |
| `png/kiwame-avatar-500.png` | GitHub / social profile picture |
| `png/kiwame-og-1200x630.png` | Link preview image (Open Graph / Twitter card) |

Everything is drawn with plain shapes and strokes - no fonts - so the SVGs render the same everywhere.

## Colours

| Name | Hex | Use |
|---|---|---|
| Vermilion (shu) | `#D63B2A` | The seal; the one accent colour |
| Sumi ink | `#1C1B1A` | Text and the wordmark on light backgrounds |
| Washi paper | `#F6F1E7` | Backgrounds; the wordmark on dark backgrounds |

## Rules of thumb

- Keep clear space around the logo of at least half the seal's width.
- Don't recolour the seal, stretch it, rotate it, or put the vermilion seal on a red background.
- Write the name **Kiwame** (capital K) in prose; the command is `kiwame`.

The SVGs are generated by `make.py` (stdlib Python, no fonts): change the geometry or colours there
and run `python3 brand/make.py` rather than hand-editing paths. Its docstring says how the PNGs and
desktop icons are produced from them.
