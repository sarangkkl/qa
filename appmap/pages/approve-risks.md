# Approve Risks

**Route:** `/approve-risks`

Approval queues for project risk and MSA review.

## Key elements
- **Manage delegations** button → `/delegations` (see pages/delegations.md)
- Tabs: **Risk Approval**, **MSA Review**
- Status filter: **Pending**
- Empty state: "No Risk Approvals To Approve"

## Notes
Which role can approve, and how items arrive in this queue (presumably when a project
reaches the "Risk Approvals" stage), is not yet mapped.
